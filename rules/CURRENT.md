Rules v1.1 consists of the locked Rules v1.0 baseline plus the approved **Organic Character Discovery** revision.

Rules v1.0 remains an immutable historical baseline. Version 1.1 changes only how a starting character's unresolved traits are established; it does not change the 2d6 resolution system, difficulty ladder, career model, injury model, RNG, or open-play rules.

Campaign checkpoint `r00000` remains a valid Rules-v1.0 historical checkpoint. Character creation upgrades the live campaign to Rules v1.1 as part of revision 1 / `r00001`.
