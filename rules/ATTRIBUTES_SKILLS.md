# Attributes, skills, specialties and qualifications — v1.0

Status: **APPROVED BASELINE — 2026-10-06**.

## Attributes

Attributes describe broad personal capability. Normal player-character creation uses values from **0 to 3**.

- **Intellect** — analysis, technical reasoning, theory, memory and problem solving
- **Perception** — observation, diagnosis, sensors, awareness and noticing anomalies
- **Presence** — communication, empathy, persuasion, bedside manner and social confidence
- **Resolve** — discipline, composure, patience, concentration and mental endurance
- **Physical** — coordination, strength, stamina and bodily control

A value of 0 is ordinary/unremarkable for a task outside the character's strengths. A value of 3 is exceptional. Species traits and unusual biology should normally be represented as explicit traits rather than assuming every member of a species has the same numeric profile.

## Broad skills

Broad skills use ranks **0–4**:

- **0 — Untrained**
- **1 — Trained**
- **2 — Proficient**
- **3 — Expert**
- **4 — Exceptional**

Core Starfleet skill families:

- Command
- Conn / Flight Control
- Engineering
- Operations
- Computers
- Science
- Medicine
- Counseling
- Security
- Tactical
- Investigation
- Diplomacy / Protocol
- Survival / Fieldcraft

The exact list may expand only through a rules revision; individual narrow expertise belongs under specialties.

## Specialties

A specialty is narrower than a broad skill and grants **+1** when it is directly relevant. Only one specialty bonus applies to a single check.

Examples:

- Engineering → Warp Propulsion
- Engineering → Damage Control
- Computers → Starship Computer Systems
- Science → Astrophysics
- Science → Xenobiology
- Medicine → Emergency Medicine
- Security → Investigations
- Conn → Shuttlecraft

The player chooses a primary and secondary specialty during character creation.

## Qualifications

Qualifications represent authorization, certification or demonstrated ability rather than generic numeric power.

Examples:

- Bridge Officer qualification
- Shuttlecraft pilot qualification
- EVA qualification
- Advanced damage-control certification
- Hazardous-material handling
- Department watch qualification
- Command qualification

A qualification may permit an action that would otherwise be inappropriate or unavailable. It does not automatically grant a numeric bonus unless the qualification explicitly says so.

## Starting Ensign baseline

The player begins as a newly commissioned Starfleet Ensign, not an incompetent novice.

Starting creation baseline:

- Attributes: assign **2, 2, 1, 1, 1**
- Primary department skill: rank **2**
- Secondary/supporting skill: rank **1**
- Two Academy cross-training skills: rank **1**
- Primary specialty: **+1 when directly relevant**
- Secondary specialty: **+1 when directly relevant**
- Remaining skills: rank **0** unless background or species traits justify otherwise

This baseline is intentionally competent without making a new Ensign a senior specialist.
